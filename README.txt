======================================

What's included:

- Profile photo: public/assets/profile.jpg
- Resume PDF: public/assets/resume.pdf
- LinkedIn: https://www.linkedin.com/in/sayeeda-nibi-6272a2436/
- GitHub: https://github.com/saydanibb12-art
- Responsive navigation, hover interactions, scroll reveal animation, project cards, resume links

RUN LOCALLY (VS CODE / LIVE SERVER):
1. Extract this ZIP folder.
2. Open the Sayeeda-Portfolio folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the Local URL printed by Vite (usually http://localhost:5173).

Note: This is a Vite project. Do not use the VS Code Live Server extension to run it.
To check the production build: npm run build
To preview the production build: npm run preview
